DESCRIPCION GENERAL

Esta primera evaluación consiste en la propuesta y planificación del proyecto
móvil que el grupo desarrollará durante el semestre. El objetivo es que definan
una problemática real, propongan una solución móvil y planifiquen su desarrollo.

El entregable es un informe escrito que documenta la propuesta del proyecto

CRITERIOS DE APROBACION DEL PROYECTO

Para que un proyecto sea aprobado debe cumplir:

1.

Ser una aplicación móvil (no web adaptada)

2. Desarrollarse con React Native (Expo)

3.

4.

Incluir al menos 2 tipos de usuario o roles diferenciados

5. Consumir al menos una fuente de datos (API propia, API pública, Firebase, o

almacenamiento local estructurado)

6. No ser una copia exacta de un tutorial de internet

7.

Ser realizable por el equipo en las semanas restantes del semestre
